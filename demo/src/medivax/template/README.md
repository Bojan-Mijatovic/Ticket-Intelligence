# MediVax

The vaccination centre's register: patients, the vaccine catalog, lots in the fridge, the doses given, and the doses due. Part of the Ticket Intelligence demo as its **pilot application**: new tickets arrive on it every working day.

All patients are **synthetic** (generated by `demo/lib/synthetic-patients.mjs` in the Ticket Intelligence repository). Their fiscal codes have the official shape but a wrong check letter, so none can belong to a real person.

| Part | Stack | Port |
|---|---|---|
| backend | Spring Boot 3, Java 21, H2 in memory, Flyway | 8084 |
| frontend | Angular 18 (standalone components) | 4204 (dev server, proxies `/api` to 8084) |
| e2e | Playwright, backend mocked | 4340 |

```
cd backend && mvn spring-boot:run
cd frontend && npm install && npx ng serve --port 4204
cd e2e && npm install && npx playwright test
```

## Screens

| Route | Screen |
|---|---|
| `/pazienti` | search by surname or fiscal code (at least 2 characters) |
| `/pazienti/:id` | the vaccination card: next doses, doses given, record a dose |
| `/scadenze` | the doses due in a week, Monday to Sunday |
| `/vaccini` | the catalog: doses, interval, age range, booster |

## Rules (backend)

| Rule | Where |
|---|---|
| A lot can be used until its expiry day, included, while it has doses left | `lot/Lot.java`, `dose/DoseService.java` |
| A patient must be in the vaccine's age range on the day of the dose | `common/Ages.java`, `dose/DoseService.java` |
| The next dose of a series is due `intervalDays` after the last one; after the series, the booster `boosterMonths` after it | `schedule/Schedule.java` |
| A dose before its day, or after a complete series without booster, is refused | `dose/DoseService.java` |

## API

| Method | Path | |
|---|---|---|
| GET | `/api/patients?q=` | search |
| GET | `/api/patients/{id}/card` | doses and next doses |
| GET | `/api/vaccines` | catalog |
| GET | `/api/lots?vaccine=` | lots of a vaccine, the first to expire first |
| POST | `/api/doses` | record a dose `{ patientId, vaccineCode, givenOn, lotCode }` |
| GET | `/api/due?from=&to=` | doses due in a period |

Errors have one shape: `{ status, error, details: ["field: message"] }`.
